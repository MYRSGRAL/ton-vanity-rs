# TON Vanity · Rust + OpenCL

Генератор собственных TON-кошельков с красивым окончанием адреса — например,
`cafe` или `2026`. Выбираешь суффикс, запускаешь поиск и получаешь новый адрес
с фразой восстановления из 24 слов.

Подходит для персонального адреса, донатов или проекта, которому хочется
узнаваемый кошелёк. Работает локально на CPU или GPU через OpenCL.

## Что умеет

- Ищет TON W5/V5R1-адреса `UQ` с суффиксом из 4–10 символов.
- Использует GPU-конвейер из двух пачек и проверяет каждую находку на CPU.
- Сохраняет прогресс и продолжает сессию после перезапуска.
- Показывает скорость, число попыток и время работы в терминале.
- Сохраняет результат в `wallets.txt` и завершает поиск.

Интернет для генерации не нужен. Программа работает на Linux и Windows.

## Установка

Для сборки нужны Rust 1.89+ и системный линкер. Для GPU — драйвер с поддержкой OpenCL.
Python, Node.js и CUDA Toolkit для запуска не требуются.

```sh
git clone https://github.com/MYRSGRAL/ton-vanity-rs.git
cd ton-vanity-rs
cargo build --release --locked
```

Бинарник: `target/release/brut-wallet` на Linux или
`target/release/brut-wallet.exe` на Windows. При заданном `CARGO_TARGET_DIR`
он находится в `release/` внутри этого каталога.

## Быстрый запуск

Скопируй бинарник в отдельную приватную папку и создай рядом `config.toml`:

```toml
schema_version = 1
target_suffix = "cafe"
device_index = 0
batch_size = 128
pipeline_depth = 2
```

Из этой папки на Linux:

```sh
./brut-wallet check
./brut-wallet search --cpu
```

На Windows PowerShell:

```powershell
.\brut-wallet.exe check
.\brut-wallet.exe search --cpu
```

Для GPU поставь `batch_size = 65536`, выбери устройство и запусти поиск:

```sh
./brut-wallet devices
# Запиши индекс нужного GPU в device_index.
./brut-wallet check --gpu
./brut-wallet search
```

На Windows используются те же команды с префиксом `.\brut-wallet.exe`.
Суффикс может содержать `A–Z`, `a–z`, `0–9`, `_`, `-`; регистр учитывается.
Начни с четырёх символов: каждый дополнительный символ сильно увеличивает поиск.

## Результат и остановка

`wallets.txt` содержит найденный адрес и 24 слова BIP39.
`session.toml` хранит прогресс: для продолжения достаточно запустить ту же команду.
Ctrl+C останавливает поиск с сохранением; повторный Ctrl+C завершает процесс сразу.

Данные по умолчанию находятся рядом с бинарником. Другой существующий каталог
можно задать через `--directory /путь/к/сессии`. Для нового суффикса используй новую папку.

**Храни `wallets.txt` и `session.toml` приватно: они дают доступ к кошелькам.**
Для импорта нужны BIP39, пустой passphrase и путь `m/44'/607'/0'`; сверь полученный
адрес с `wallets.txt` перед использованием кошелька.

## Полезные команды

| Команда | Для чего |
|---|---|
| `check` | Проверить CPU на публичных тестовых данных |
| `check --gpu` | Дополнительно проверить GPU |
| `devices` | Показать устройства OpenCL |
| `benchmark --cpu` / `benchmark` | Измерить скорость CPU / GPU |
| `search --cpu` / `search` | Начать или продолжить поиск |
| `search --cpu --batches 1` | Выполнить одну CPU-пачку |
